# mini-classroom · 微课堂

**说出你想学什么，从一节约 10 分钟的学习开始。**

微课堂把你想学的内容拆成小步，准备讲解和练习，再根据作答安排复习。你可以把时间用在**理解、练习和提问**上，少花精力决定“今天学什么、什么时候复习”。

**本机运行 · 自选 AI 模型 · 学习记录保存在自己的电脑**

[看看能帮你做什么](#你能得到什么) · [开始使用](#开始使用) · [参与开发](#参与开发)

## 你能得到什么

### 1. 从一个想法，找到学习起点

先说出想解决的问题，不用准备完整的学习计划：

> 我想学会制作一个 Skill，把会议记录整理成会议纪要。

AI 会和你聊清楚**学来做什么、已经会什么、这次学到哪里**。你确认范围后，再开始准备学习内容。

做一次摸底，可以减少重复学习已会的内容。也可以跳过，直接从基础开始。

![把制作会议纪要 Skill 的目标拆成知识点，选取触发条件作为今天约 10 分钟的学习内容](docs/assets/readme/topic-to-lessons.png)

![学习目标澄清页：通过对话明确目的、范围和已有基础，确认后才加入学习计划](docs/assets/screenshots/topic-planning.png)

### 2. 用一小段时间，学一点、练一下

打开微课堂，先看这一节的安排。默认约 **10 分钟**，也能调整时长；系统会穿插复习、正在学的内容和新知识。

- **看懂一个要点**：通过例子、类比或图解理解它。
- **试试自己会不会**：回答选择题、简答题，或完成补全、修正练习，并查看反馈。
- **把没懂的地方问清楚**：直接追问，或选中一段内容提问，不用切换到其他聊天工具。

![练习写 Skill 的触发条件：从“需要总结时使用”得到范围过宽的反馈，再改成具体的会议纪要使用场景](docs/assets/readme/practice-and-feedback.png)

![学习页：阅读讲解与图解、提交自己的作答，并查看针对性反馈和参考答案](docs/assets/screenshots/learning-feedback.png)

### 3. 让系统记住该复习什么

**不用自己维护复习日历。**微课堂根据作答和自评，安排知识点下次出现的时间。答错后更早复习，掌握较稳后再拉长间隔。

有内容需要巩固时，它会进入后续学习安排。再次打开，就能继续练习。

![“明确用途”回答熟练后拉长复习间隔，“写触发条件”还不清楚时安排较早复习](docs/assets/readme/learning-and-review.png)

![“今天”页面：查看本节进度、复习与新学内容、提醒时段和当天学习记录](docs/assets/screenshots/today.png)

**觉得 AI 判错了，可以申诉。**发现已经学过的内容没弄懂，也能主动选择重新学习。

### 4. 看清学到哪，按自己的节奏继续

打开认知地图，就能一起查看不同主题的学习情况：**已经学会什么、今天该复习什么、下一步能学什么**。

![用制作会议纪要 Skill 的知识点展示已掌握、待巩固、下一步可学和尚未学习的内容](docs/assets/readme/knowledge-map.png)

![认知地图：通过知识点卡片查看掌握阶段、到期复习、下一步可学和暂未解锁的内容](docs/assets/screenshots/cognitive-map.png)

点开知识点，可以回看自己怎么答、哪里答错，以及用自己的话建立的知识联系。暂时不想学的内容可以排除，想继续时再恢复。

### 5. 需要用时，找回学过的内容

不用从头翻阅全部学习记录。按主题生成**速查表**，集中查阅常用概念和容易混淆的地方。

想放进自己的笔记工具时，可以将知识点、作答记录和速查表**导出为 Markdown**。

## 开始使用

**桌面版安装后即可打开，无需安装 Node.js、pnpm 或 WSL。**先准备模型服务的接口地址、模型名称和 API 密钥。

### 第一步：安装并启动

在项目 [Releases](https://github.com/pipdax/mini-classroom/releases) 页面或维护者提供的测试包中，选择与电脑匹配的版本：

- **macOS**：Apple 芯片选择 `arm64`，Intel 选择 `x64`。打开 `.dmg`，将“微课堂”拖入“应用程序”，再从那里启动。
- **Windows**：选择 `x64` 的 `.exe` 安装程序，按向导安装，再从开始菜单打开。
- **Linux**：Ubuntu / Debian 选择 `x64` 的 `.deb`；其他发行版可尝试 `.AppImage`，在文件属性中允许作为程序运行后打开。

**v1.2.0 桌面版目前为测试包，尚未完成 macOS 开发者签名、公证和 Windows 代码签名。**系统可能提示无法验证开发者；请核对下载来源与发布说明，不要关闭系统安全功能。三平台已通过自动构建和打包应用启动检查，完整安装、升级与卸载的验证范围见 [发布检查](docs/releasing.md)。

如果发布页尚未提供你的系统对应的安装包，可以按 [开发指南](docs/development.md#从代码到可运行应用) 从源码运行或构建。

### 第二步：连上自己的 AI 模型

打开 **设置 → AI 模型**，填写连接信息，测试成功后保存。

- 支持 **OpenAI 兼容接口、Anthropic、Google** 三类格式，实际模型以服务商支持为准。
- 使用 OpenAI 兼容接口时，填写完整基础地址，通常包含 `/v1`。
- **图像模型可以先留空**。不配置它，也能使用文字讲解和代码图解。

桌面版直接在设置页配置即可。从源码运行时的高级配置和 `.env` 用法见 [开发指南](docs/development.md#环境配置)。

### 第三步：完成第一节微课堂

1. **选一个主题**：在首页输入想学的内容，和 AI 聊清楚目标后确认。
2. **确定起点**：等待内容生成，完成或跳过摸底。
3. **开始学习**：跟着讲解完成练习，答对后按自己的感受选择自评。

学完后，到“今天”查看安排，或去认知地图回看所学。首次生成、内容不足或临时改变学习要求时，需要等待模型响应。

**用完后关闭所有微课堂窗口，应用就会退出并停止后台生成。**退出不会删除学习记录。

### 更新与导入旧记录

第一版采用手动更新：先退出微课堂，再安装新版。学习记录和设置单独保存在电脑的用户数据目录，正常覆盖安装会保留它们。可通过菜单 **文件 → 打开学习数据文件夹** 找到数据；请勿删除该目录。

以前从源码运行过微课堂的用户，先在旧项目中运行 `pnpm stop`，再打开桌面版的 **文件 → 导入旧版学习记录…**，选择旧项目的 `data/weiketang.sqlite`。导入会复制旧记录和设置，不会改写旧文件；请在桌面版开始使用前导入，已创建主题、学习或保存设置后不能覆盖导入。导入后会继续尚未完成的内容生成，可能产生模型费用。

如果旧版只通过 `.env` 配置模型，请先在旧版设置页保存配置，再停止旧服务并导入；`.env` 文件不会随数据库导入。

## 使用前知道这 4 件事

1. **后台准备内容会调用模型并可能计费。**暂时不用时，关闭所有桌面窗口以退出；从源码运行的用户需要执行 `pnpm stop`，只关闭浏览器不会停止服务。
2. **模型需要处理你的学习内容。**主题、作答等内容会发送到你配置的服务；设置页保存的密钥在本机数据库中明文存储。页面也会加载 Google Fonts，详见 [安全说明](SECURITY.md)。
3. **目前只供本人在本机使用。**没有登录认证，请勿直接开放到局域网或公网。提醒需授权并保持页面或应用运行；不支持离线学习，也不能只靠 GitHub Pages 运行完整应用。
4. **AI 的讲解和批改可能有误。**遇到疑问可以追问、申诉或核对资料。

桌面版的学习数据可从 **文件 → 打开学习数据文件夹** 查看；源码版默认位于 `data/weiketang.sqlite`。不要公开学习数据库、`.env`、`data/` 或 `.run/`，分享导出文件前也要检查其中的个人内容。

## 参与开发

项目使用 **React + TypeScript、Node.js + Hono、SQLite、Electron**。安装开发环境、源码运行和桌面打包方式见 [开发指南](docs/development.md)。

修改后运行：

```bash
pnpm check
```

它会执行类型检查、自动测试和前端构建。测试使用模拟模型和内存数据库，**不需要真实密钥，也不会改写你的学习记录**。
